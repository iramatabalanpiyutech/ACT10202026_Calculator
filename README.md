# ACT10202026_Calculator
This program is a simple calculator made using NASM 32-bit Assembly Language. It can perform 
four basic operations: addition, subtraction, multiplication, and division. When the program 
runs, it displays a menu where the user can choose an operation by entering A, S, M, or D. After 
choosing, the user enters two numbers, and the program calculates and displays the result. It 
also supports two-digit numbers. The program uses procedures with CALL and RET instructions 
to perform each operation. It also uses loops and conditional jumps to control how the program 
works. After showing the result, the program asks if the user wants to try again. If the user 
enters Y, the menu appears again. If the user enters N, the program ends
